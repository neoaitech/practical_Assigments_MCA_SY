# Smart Attendance Management System

A full-stack Attendance Management System developed to manage students, teachers, attendance records, and reports digitally.

## Features

- Admin Dashboard
- Teacher Management
- Student Management
- Attendance Tracking
- Attendance Reports
- Student Attendance Percentage
- MongoDB Database Integration
- REST API Backend
- Docker Support

## Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose

### Tools
- Git & GitHub
- Docker
- Jenkins (CI/CD)
